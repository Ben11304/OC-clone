MCP Beta

Assistant Tool Access

The MCP server exposes OpenConstruction catalog capabilities to compatible assistant clients through structured tools. Local stdio is the recommended setup because it can download datasets into a user-controlled directory; OC OAuth is not required.

search_resources

Search public OpenConstruction catalog resources.

get_resource

Fetch one resource by type and id.

compare_resources

Compare catalog entries for a task or reuse goal.

run_dataset_discovery

Run the Dataset Discovery skill with structured inputs and ranked results.

get_catalog_stats

Summarize the loaded catalog snapshot.

ask_openconstruction

Answer a user question using catalog evidence.

list_skills

List skill definitions from the repo-owned registry.

get_skill

Fetch one skill definition by id.

get_dataset_download_plan

Resolve a dataset's direct, programmatic, or manual acquisition route without writing files.

download_dataset

Start a license-confirmed local download, or return safe provider login guidance when authentication is missing.

get_download_status

Inspect progress and files for a local background download job.

cancel_download

Request cancellation of a local background download job.

download_dataset, get_download_status, and cancel_download are local stdio tools because a remote MCP server cannot write into the user's filesystem. The read-only download-plan tool is available through both transports.

Dataset-provider authentication remains on the user's machine and does not require OC OAuth. An auth_required result tells the agent which official local login flow to use and how to retry. Agents must never request tokens, passwords, OAuth codes, cookies, or credential files through chat.

        Manual setup fallback
        

          

            
Install with uv

            
Clone the official source and create an isolated Python environment.

            

              

git clone https://github.com/Ben11304/OC-mcp.git
cd OC-mcp
uv sync --python 3.12 --frozen

            

          

          

            
Register the stdio server

            
Use your client's native MCP configuration and run openconstruction-mcp from the isolated project environment.

            

              

uv --directory /absolute/path/to/OC-mcp run --frozen openconstruction-mcp
