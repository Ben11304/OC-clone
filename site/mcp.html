Manual installation

Codex

Install the package from PyPI, then register its local MCP command.

python -m pip install --upgrade openconstruction
codex mcp add openconstruction -- openconstruction-mcp

Claude Desktop

After pip install --upgrade openconstruction, add its MCP command to the Claude Desktop configuration.

{
  "mcpServers": {
    "openconstruction": {
      "command": "openconstruction-mcp"
    }
  }
}

Download datasets from the CLI

Install once with pip install --upgrade openconstruction. The oc command then uses the same provider adapters, local dataset library, resume checkpoints, progress reporting, and checksums as the MCP.

Choose what to install

A normal command downloads the dataset only. Add --paper when you also want the related research paper in the same package.

Dataset only
oc download TunGPR --accept-license
Dataset and related paper
oc download TunGPR --paper --accept-license
Dataset, paper, and a custom library
oc download TunGPR --paper --accept-license \
  --library-dir /data/openconstruction
  • --paperResolve the paper from the OpenConstruction paper catalog and save the original PDF without conversion.
  • --accept-licenseConfirm that you reviewed and accepted the dataset license and source terms shown by the CLI.
  • --library-dirInstall into a library you choose instead of ~/.openconstruction/datasets.
  • --destinationChoose the safe dataset-directory name inside the selected library.

What you receive

With --paper, a completed installation keeps the dataset and its paper together with one provenance manifest.

TunGPR/
├── dataset files…
├── papers/
│   └── paper.pdf
└── .openconstruction-manifest.json
Safe to resume. Interrupted HTTP downloads retain partial files and continue on the next matching command. Existing files from a different source are not overwritten.
One OC command. Public HTTP, Zenodo, Figshare/DTU Data, and Hugging Face sources are downloaded through OC provider adapters. GitHub is launched through OC and currently requires Git to be installed locally.
Paper availability. If no paper is registered, the CLI reports it and still completes the dataset. If an available paper fails to transfer, the dataset remains on disk and the command returns a non-zero status.
Verification. OpenConstruction verifies declared file sizes and SHA-256 checksums, then records the dataset and paper provenance in the manifest.
